# Banking Analytics — End-to-End Data Analytics Project

## Project Overview
This project focuses on analyzing banking data to understand customer accounts, transactions, loans, credit profiles, and merchant activities.

The project uses PostgreSQL, Python, and Power BI to perform data analysis and present meaningful insights through interactive dashboards.

## Project Objectives
- Analyze customer and account information.
- Understand transaction patterns and trends.
- Explore loan distribution and credit-related metrics.
- Analyze merchant and card information.
- Present key performance indicators through dashboards.

## Tools & Technologies
- **Database:** PostgreSQL
- **Programming:** Python (Pandas, NumPy, Matplotlib, Seaborn)
- **Data Visualization:** Matplotlib, Seaborn, Power BI
- **Analysis:** SQL, Exploratory Data Analysis (EDA)

## Dataset Overview
- 50,000 customers
- 75,000 accounts
- 100,000 cards
- 5,000 merchants
- 500 branches
- 30,000 loans
- 1,000,000 transactions

**Total: 1,260,500 records across 7 tables.**

## Project Workflow
1. Data understanding and validation using SQL.
2. Data analysis using PostgreSQL queries.
3. Exploratory Data Analysis using Python.
4. KPI development and dashboard creation in Power BI.
5. Identification of key trends and insights.

## Key Insights
- Total transaction value: approximately **$5.00 billion**.
- Total account balance: approximately **$7.51 billion**.
- 2024 recorded the highest annual transaction value.
- August recorded the highest monthly transaction value.
